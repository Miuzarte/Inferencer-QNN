# Inferencer-QNN

用 flutter / kotlin / go 实现在骁龙设备上调用 QNN HTP 后端推理 yolo

详细信息见子项目目录

结果成本: 10RMB DeepSeek-V4-Flash-0731

- Android 推理运行时: [ONNX Runtime](https://github.com/microsoft/onnxruntime)
